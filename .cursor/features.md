# Features

## Foundation

- [*] Unique username, display name, avatar, and password. An avatar can be a PNG, JPG, GIF, or WebP, cropped and zoomed to a circle, and removed back to the letter. Sign-in has **Stay signed in**: checked writes `client-session.json` for relaunch; unchecked keeps the token in memory only and clears any saved file. Log Out always clears the saved session.
- [*] User profiles (Discord parity): view banner, themed card, avatar decorations, styled display name, pronouns, custom status, About Me, Member Since, connections, and Board/Activity/Wishlist widgets; edit with a Discord-style customization editor (nameplate, decorations, display-name style, theme & banner, profile effect/frame, widgets). Includes badge row, Activity/Wishlist tabs, Discord slot chrome, board game cards, and Save/Cancel for banner/avatar; custom status on presence; Main vs server profile switch; clickable connections. Profile view and customization editor use dedicated overlay windows with clipped identity / left / preview / board columns so panels no longer overflow or collide (BA-73). Open from chat, the member list, friends, or the user-bar avatar.
- [*] Friend requests and a friends list. Accepting a request (or completing a mutual add) opens that friend's DM.
- [*] Create a server, join by invite, member list, and server nickname
- [*] Nested server-rail folders with custom hex colors (BA-79): create/rename/delete, nest servers and subfolders, collapse/expand (persisted), color via hex + RGB sliders; per-user Postgres layout
- [*] Customizable Home landing (BA-81): Lucide home icon on the top server-rail control (formerly the DM/home letter mark); opens a Home page with rearrangeable/show-hide sections (Friends, Direct Messages, Servers, Recent) persisted in `home.json` under the Banter data directory. Sidebar Friends still opens the full people list.
- [*] Text and voice channels in categories. Channels may optionally use a Lucide icon (picker on create/edit); the sidebar and header fall back to hash / volume-2 / pencil when unset. Anyone with Manage Channels can set or clear the icon.
- [*] Send, reply, edit, delete, and search. Text channels and DMs use Reddit-style nested reply threads (24 px indent, thin vertical gutters, circular (−)/(+) collapse with line-click, always-visible Reply link, accented inline composer vs top-level bar). Leaf rows keep Discord-like avatar, time, and hover toolbar polish. Message bodies use **BFMD** (Better Formatted Markdown) for styles: bold, italic, underline, strikethrough, size, color, highlight, font, align, heading, horizontal rule, emote size `{e}` (default 22px), and **masked links** `{l:"https://…"}` plus Discord sugar `[label](url)`. Clicking a masked link always opens a confirm popup that shows the real destination URL (Cancel / Open) before any navigation. Plain text remains valid BFMD. Message rows render styled runs in ImGui; paste/typed BFMD commands still parse. No composer B/I/U/S format toolbar (BA-94).
- [*] Emote Library (BA-83): user/server packs (mixed emote/sticker/GIF), upload with Carbon size caps + **15s** GIF duration gate (classic + video), personal subscribe + server auto-offer, composer Emotes/Stickers/GIFs picker (Server/Subscribed), stable `:{e:id}:` emote tokens, Model A sticker-primary send, GIF message media. No mock/seed packs. Unicode emoji keyboard and reactions stay deferred. See `docs/emote-library.md`.
- [*] Attach a file from the composer is temporarily disabled (BA-61): the attach control opens a Banter dialog that says exactly `Currently Unavailable` instead of uploading.
- [*] Discord-style right-click menus on messages, members/friends/DMs, and channels (foundation actions only; kick/ban stay deferred)
- [*] Drop-in voice with mute, deafen, push-to-talk, camera, and screen share. Voice & Video settings and stream quality drive the engine and are saved on this PC. Resolution and frame rate are also on the stage stream-options chevron so they can change while live without opening Settings. Stream Select / Screen Share source previews use an arched cover-flow of tall portrait panels (BA-96): soft fade + rise from bottom, center focused with edge dimming, wheel/arrows/click cycle focus, and a bottom-middle frosted glass stream-settings chip. Stream audio mix sources are grouped under Audio channels and Apps. Voice/media failures use stable `BANTER_*` codes on the red notice strip (not opaque `request failed` or raw WASAPI/DXGI `0x80070057`); see `docs/errors.md` (BA-87 / BA-88 / BA-92 / BA-100). On Windows, Go Live falls back to paced GDI capture when DXGI `video_recorder` returns `E_INVALIDARG`; Linux PipeWire/X11 paths stay unchanged. Interactive VC latency: ~60 ms playout margin, ~200 ms PCM backlog caps, FPS-matched video RTP duration, 1 s default keyframe, OpenH264 bitrate/low-complexity/single-thread, Opus complexity 5, tighter SFU forward queues (BA-97). Encoder quality/CPU: cached HW probe, HW-first without dual OpenH264 open, screen/camera QP floors, richer Half/Quarter layer bitrate, Linux HW CBR/VBR + NVENC zerolatency (BA-101).
- [*] Stream watch (BAN-9 / BAN-13): pop out a Banter Stream OS window, cycle between users who are currently sharing, and fullscreen theater with chrome that fades on idle and returns on mouse move. Pop-out and fullscreen show profile icons and voice indicators (talking ring, mute/deafen) for live sharers that fade with the chrome.

- [*] 1:1 direct messages that can start a call. Starting or accepting a call opens a Discord-style call stage in that DM (large avatar while ringing, two tiles when active, shared call controls).
- [*] Presence and mentions
- [*] GLFW + OpenGL window with Dear ImGui docking
- [*] Vendored UI + chat fonts: **Dongle** for UI chrome (default ImGui face + bold/semibold labels); **Shantell Sans** for chat / BFMD message bodies (regular / bold / italic / bold-italic). OFL faces under `crates/banter/assets/fonts/`.
- [*] Custom Mac-style title bar (BA-105 / BA-111): on Windows, undecorated GLFW windows with a short dark client-drawn caption, left traffic-light close / minimize / maximize, drag-to-move, double-click maximize, and client edge-resize (GLFW drops OS resize when undecorated); windows open centered on the primary monitor. ImGui shell hosts sit below the caption so drag/lights keep their hits. Applies to Banter, Banter Settings, and Banter Stream. Hidden in OS fullscreen. Linux keeps the system / DE title bar (`client_caption_enabled` false, `Decorated` + `Resizable`) so compositor chrome and user themes work.
- [*] User Settings in a dedicated Banter Settings GLFW window (My Account, Voice & Video, Developer); main shell stays usable; Escape / close returns focus cleanly. My Account edits display name, About Me, and custom status. Custom status shows under your name and on member rows.
- [*] Server Settings in a dedicated Banter Server Settings GLFW window (BA-106): Discord-like left nav + content pane opened from the server header gear, server dropdown, or rail right-click. Overview (name + nickname + invite), Roles (live CRUD), Badges (coming soon — no community-badge API yet), Member List (live hoist preview + assign roles). Separate from User Settings; shares the secondary OS-window host. Unblocks BA-23 walk inside Settings.
- [*] Guild roles: @everyone plus extra roles with a color, optional hoist, and permission bits (administrator, manage channels, manage roles, create invite). Edited in Server Settings → Roles (server menu / gear still open that page). Member context menu assigns them. Owner has every permission. Kick and ban stay deferred.
- [*] Developer settings: Local (`127.0.0.1:3970`) or Remote host, persisted in `dev-server.json`. Client startup does not require local unless logged in on Local or the user picks Local; missing local asks for remote instead of hard-failing. Shows client/server Banter version + protocol; on connect the client blocks incompatible/stale hosts with `BANTER_SERVER_TOO_OLD` / `BANTER_CLIENT_TOO_OLD` / `BANTER_VERSION_UNREACHABLE` (BA-91).
- [*] Version system: shared `BANTER_VERSION` label + numeric `protocol` on `GET /v1/health` and `GET /v1/version`; client compares protocol floors (not equal strings) so a newer client refuses a pre–version-system / too-old server.
- [*] F3 profiler: FPS, RSS, HTTP/WebSocket bytes, frame sections, expensive ops
- [*] Hidden composer command `/debugnow` (text channels and DMs) opens a server debug window with logs, live stats (including server version + protocol), and HTTP/WS/media in+out traffic. It is not listed in the UI and is not sent as a message.
- [*] Chat slash/prefix commands (BA-104): Discord-like composer popup (Tab/Enter), per-guild configurable prefix + aliases (persisted; Chat Commands in the server menu), client `CommandRegistry` with built-ins `me`, `shrug`/`shruggie`, `tableflip`, `mute`, `deafen`, `join`, stub `nick`, hidden `debugnow`. Docs: `docs/chat-commands.md`.
- [*] Display settings: VSync, fullscreen, window resolution (saved in video.json). With VSync on, the client UI matches the current monitor’s refresh rate and reapplies when the window moves or the display mode changes (not stream capture FPS).
- [*] Chat compose autosuggest (BA-103): while typing in the bottom composer, Banter shows suggestion chips and ghost text for `@` member mentions, optional `:emote:` shortcodes when an emote-name hook is supplied, and next-word / phrase completions from a local bigram/trigram model over recent channel history plus static common chat phrases. Tab or click accepts; Escape dismisses until the draft changes. No cloud LLM. See `docs/chat-autosuggest.md`.
